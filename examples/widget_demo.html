🚀 CRAFT Widget Demo

This page demonstrates the CRAFT chat widget integration. Click the chat button in the bottom-right corner to start chatting!

⚡ No Dependencies

Pure vanilla JavaScript, works anywhere

🎨 Customizable

Light/dark themes, positioning, colors

💬 Real-time

Streaming responses for instant feedback

🔒 Secure

API key authentication & rate limiting

⚠️ Note: Make sure the CRAFT API server is running at http://localhost:8000 before testing the widget.
Run: python examples/api_server.py
