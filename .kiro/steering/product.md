# CRAFT Product Overview

CRAFT (Chatbot & RAG Framework Toolkit) is a provider-agnostic Python framework for building intelligent chatbots with RAG capabilities.

## Core Value Proposition

- Switch between 6+ LLM providers (Anthropic, OpenAI, Google, Azure OpenAI, AWS Bedrock, Cohere) with one line of code
- Complete RAG system with embeddings, vector stores, and retrieval
- Production-ready with persistent storage, API server, and observability integrations
- Easy integration via REST API, WebSocket, React components, and vanilla JS widget

## Key Features

- Provider abstraction layer for LLM flexibility
- Streaming support across all providers
- Conversation management with persistent storage (SQLite, PostgreSQL, Redis, MongoDB)
- RAG with multiple vector stores (ChromaDB, FAISS, Pinecone)
- Document loaders (PDF, CSV, Web)
- FastAPI server with WebSocket support
- MCP (Model Context Protocol) integration
- Production observability (Langfuse, Prometheus, OpenTelemetry, Sentry)
- Multi-language support (i18n)
- React and vanilla JS components for web integration

## Target Users

Developers building chatbot applications who need provider flexibility, RAG capabilities, and production-ready infrastructure without vendor lock-in.
